# 前端学习路径图谱（后端工程师 → 全栈）· 实施计划

## 1. 概述（Summary）

为「后端工程师转型全栈」产出一份**前端学习路径思维导图**，交付形态为 **Markdown 大纲**（可导入 XMind / 幕布 / ProcessOn）。

- 技术栈基线：**Vue 3**（Composition API + `<script setup>`）＋ **TypeScript 优先** ＋ **ant-design-vue 4.x** ＋ **vxe-table 4.x** ＋ **公司私有组件库**。
- 学习路径按 **入门 → 进阶 → 高级** 三级拆分。
- 核心原则：
  - **入门**：学完即可独立完成一个标准中后台 CRUD 模块（列表 + 筛选 + 分页 + 新增/编辑/详情 + 接口联调），以「够用、可上手」为准，不求精通。
  - **进阶/高级**：通过真实项目任务「边干边学」补全，不脱离业务空学。
- 每个知识点挂「学习资料」子节点：入门只用官方文档 + 免费博客 + 视频；进阶、高级可引入书籍。

## 2. 现状分析（Current State Analysis）

- 工作目录 `f:\trae-project\full_stack_trans` 为空，无现有代码、无私有组件库源码/README 可供核对版本与封装约定。
- 因此本图谱基于用户口述技术栈设计，私有组件库、登录鉴权、接口规范等公司特有内容以「占位 + 归口到内部资料」方式处理，并标注需公司侧补充链接。
- 产出物为**纯内容交付**（单个 Markdown 文件），不涉及代码改动。

## 3. 关键决策与假设（Decisions & Assumptions）

| 项 | 决策 |
|---|---|
| Vue 版本 | Vue 3，逻辑主线用 Composition API（`<script setup>`），Options API 仅作「看懂老代码」备注 |
| 语言 | TypeScript 优先，入门阶段即引入「够用的 TS」，进阶系统补类型系统 |
| 交付格式 | 单个 Markdown 大纲文件（嵌套无序列表），可直接导入 XMind / 幕布 |

| 学习者画像 | 假设后端工程师以 Java/Go/C# 等强类型语言为主；在「JS 语法基础」节点注明：Node.js 后端可跳过该枝 |

| 私有组件库 | 图谱中以「公司私有组件库使用规范」为节点，学习资料指向内部文档，具体链接留占位符待公司补充 |

## 5. 图谱完整内容结构（Proposed Mind Map — 全节点树）

### 5.1 根节点
`前端学习路径图谱 · 后端工程师转全栈（Vue3 + TypeScript + ant-design-vue + vxe-table，中后台场景）`

### 5.2 入门级（学完即可独立完成一个 CRUD 模块）
无需书籍，资料 = 官方文档 + 免费博客 + 视频。

1. **前端三件套速成**（够用即可，Node 后端可跳过本枝）
   - HTML 语义化与常用标签、表单控件 → MDN
   - CSS 盒模型、选择器、Flex/Grid 布局、定位、常见居中 → MDN / 阮一峰博客
   - JavaScript 核心语法：变量/作用域/闭包、`this`、数组/对象常用方法
   - ES6+：`let/const`、箭头函数、解构、模板字符串、扩展运算符、`Promise`/`async-await`、模块化 `import/export` → 《现代 JavaScript 教程》(zh.javascript.info)、阮一峰《ES6 标准入门》
2. **TypeScript 够用入门**
   - 类型标注、`interface`/`type`、联合/交叉类型、泛型入门
   - 与 Vue 结合的基础用法（`defineProps`/`defineEmits` 类型、`ref<类型>`）
   - 与后端 DTO 打通的思想（对接接口返回类型）→ TS 官方中文 Handbook
3. **工程化环境（够用）**
   - Node/npm/pnpm 环境、Vite 脚手架（`npm create vue`）
   - 项目目录结构认知、Vue DevTools 安装与基本使用 → Vite 官方文档
4. **Vue 3 核心（入门口径）**
   - 模板语法、条件/列表渲染、事件绑定、样式绑定
   - 响应式基础：`ref`/`reactive`、`computed`、`watch`、生命周期
   - 组合式 API：`<script setup>`、`defineProps`/`defineEmits`
   - 组件基础：props/emit、父子通信 → Vue 3 官方文档（中文）
5. **组件库实战（上手核心）**
   - ant-design-vue 4.x 常用组件：按钮/表单/表格/弹窗/布局/日期/选择器/消息提示 → 官方文档
   - vxe-table 4.x 基础：列配置、分页、排序、筛选、行选中、工具栏 → 官方文档与示例
   - 公司私有组件库：注册方式、文档入口、使用约定、主题/约束（资料指向内部文档，占位待补）
6. **一个真实 CRUD 模块实战**（把上述串起来）
   - 用 ant-design-vue Form + vxe-table 写「列表 + 筛选 + 分页 + 新增/编辑弹窗 + 详情」
7. **接口联调与网络**
   - `fetch`/axios 封装、请求/响应拦截器、token 携带
   - Vite 开发代理解决跨域、分页/筛选参数对接后端
   - 对接口的约定（错误码、`code/message/data` 结构）→ axios 文档 + 公司接口规范（内部）
8. **代码规范与协作（轻量）**
   - ESLint/Prettier、commit 规范、PR 协作（后端已有基础，一带而过）

### 5.3 进阶级（边干边学，通过项目任务驱动补全）
允许书籍。

1. **Vue 3 深入**
   - 响应式原理：`ref`/`reactive` 底层 Proxy、依赖收集、`nextTick`
   - 组件设计：插槽 slot（具名/作用域）、`provide/inject`、动态/异步组件、render 函数
   - 组合式函数 composables 的封装套路
2. **状态管理 Pinia**
   - store/state/getter/action、模块划分、持久化、与接口联动的实践
3. **路由 Vue Router**
   - 嵌套路由、导航守卫、权限路由、懒加载、路由元信息
4. **TypeScript 进阶**
   - 泛型深入、工具类型（Partial/Pick/Omit/Record）、实用类型模式、与组件库/接口类型联动
5. **工程化进阶**
   - Vite 配置与优化、环境变量、按需加载/Tree-shaking、构建产物分析与代码分割
   - ESLint/Prettier/Husky/commitlint、前端 CI/CD（轻量）
6. **性能优化**
   - 懒加载、`keep-alive`、渲染优化、列表虚拟滚动
   - vxe-table 大数据量优化（虚拟滚动、性能配置）
7. **CSS 进阶与主题**
   - SCSS/Less 预处理器、CSS 变量、作用域（scoped/module）、主题定制与私有组件库样式规范
8. **调试能力进阶**
   - Chrome DevTools：Network/Performance/Source、SourceMap、断点与性能定位
9. **前端安全（后端视角衔接）**
   - XSS/CSRF 基础、输入转义、依赖库漏洞关注
10. **与后端协作规范**
    - OpenAPI/Swagger 接口文档 → 前端类型生成、错误码约定、联调协作流程

3. **工程化高级**
   - Vite 插件开发、自研脚手架/构建链路定制、微前端（按需）、Monorepo 与发布体系
4. **前端架构与设计系统**
   - 大型应用分层与目录设计、多端/多项目复用
   - 私有组件库开发与维护：封装规范、按需引入、文档化、单元测试、版本发布流程

6. **可视化与复杂场景（按需）**

7. **前沿与团队能力**
   - Vue 生态动向（如 Vapor Mode、新特性）、Composition API 最佳实践沉淀、跨端（小程序/uniapp，按需）
   - 面向前端的代码评审、重构、知识沉淀与技术分享
8. **书籍清单（挂在该级或对应知识点下）**
   - 《JavaScript 高级程序设计（第 4 版）》（红宝书）
   - 《Vue.js 设计与实现》（霍春阳）
